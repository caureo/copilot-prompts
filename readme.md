# IA que Orienta — Criando Seu Roteiro de Carreira

## Sobre o projeto

Projeto desenvolvido como parte de um desafio da DIO, utilizando inteligência artificial para identificar carreiras compatíveis com o perfil profissional do usuário e criar um plano de desenvolvimento personalizado.

## Objetivo

Utilizar agentes de inteligência artificial para analisar experiências, interesses, habilidades e objetivos profissionais, gerando recomendações de carreira e um roteiro de estudos.

## Tecnologias utilizadas

- Microsoft Copilot
- Inteligência Artificial Generativa
- Engenharia de Prompts
- GitHub
- Markdown

## Funcionamento

### Agent 1 — Entrevistador de Carreira

Responsável por realizar uma entrevista de sete perguntas, analisar o perfil profissional e sugerir três carreiras compatíveis.

### Agent 2 — Planejador de Carreiras

Responsável por utilizar as informações coletadas pelo entrevistador e gerar um plano de estudos personalizado.

## Resultados obtidos

O projeto foi testado utilizando meu próprio perfil profissional, com 14 anos de experiência em tecnologia e disponibilidade de 4 horas semanais para estudos.

As carreiras sugeridas foram:

| Carreira | Pontuação |
|---|---|
| Engenharia de IA e Automação | 19/20 |
| Cloud e DevOps | 18/20 |
| Segurança da Informação | 17/20 |

**Carreira escolhida:** Engenharia de IA e Automação.

## Roadmap de aprendizado

Foi elaborado um plano de 90 dias, dividido em três etapas:

- Mês 1: Fundamentos de IA Generativa, Python e APIs.
- Mês 2: Desenvolvimento de aplicações com IA e RAG.
- Mês 3: Construção de projeto de portfólio e preparação para entrevistas.

## Projeto de portfólio proposto

Copilot de Infraestrutura e Suporte Inteligente: assistente de IA capaz de consultar documentações técnicas e auxiliar na resolução de problemas de infraestrutura.

## Aprendizados

Durante o desenvolvimento deste desafio, pude aplicar conceitos de engenharia de prompts, personalização de respostas, transferência de contexto entre agentes e utilização de inteligência artificial para planejamento profissional.

## Possíveis melhorias futuras

- Automatizar a comunicação entre os agentes.
- Desenvolver uma interface web.
- Exportar o plano de carreira em PDF.
- Implementar acompanhamento da evolução dos estudos.
